Diseño de Filtros Digitales con Python
Objetivo
Diseñar e implementar filtros digitales pasa bajos, pasa altos y pasa bandas utilizando Python para analizar señales con ruido.

Herramientas utilizadas
Python
NumPy
SciPy
Matplotlib
Visual Studio Code
GitHub
Filtros implementados
Filtro pasa bajos
Filtro pasa altos
Filtro pasa bandas
Filtro FIR
Resultados
Se generó una señal compuesta por frecuencias de 50 Hz y 200 Hz con ruido blanco. Posteriormente se aplicaron distintos filtros digitales para analizar su comportamiento y capacidad de eliminación de ruido.
